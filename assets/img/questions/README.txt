Put the question screenshots here, named after the question id: a01.png ... a23.png, b01.png ... b23.png.
The file name for each question is the `image` field in assets/js/data.js (change it there to use .jpg etc.).
Questions without an `image` field (a19, a21, a23, b19-b23) need no screenshot.
A missing file shows a "Screenshot not added yet" box and a console warning.
